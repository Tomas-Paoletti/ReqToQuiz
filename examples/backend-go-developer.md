# Backend Developer (Go) — Semi Senior

Somos una fintech que procesa pagos para comercios en Latinoamérica. Buscamos una persona Backend Developer para el equipo de Payments.

## Responsabilidades
- Diseñar y mantener microservicios en Go que procesan miles de transacciones por minuto.
- Exponer APIs REST y consumir servicios vía gRPC.
- Modelar datos en PostgreSQL y optimizar consultas.
- Publicar y consumir eventos con Kafka.
- Escribir tests unitarios y de integración.
- Participar de code reviews y guardias on-call.

## Requisitos
- 3+ años de experiencia en desarrollo backend.
- Go (goroutines, channels, context, manejo de errores).
- SQL y PostgreSQL (índices, transacciones, niveles de aislamiento).
- Docker y nociones de Kubernetes.
- Git y CI/CD.
- Buenas prácticas de diseño de APIs REST.

## Deseable
- Kafka o RabbitMQ.
- Observabilidad (Prometheus, Grafana, OpenTelemetry).
- Experiencia en pagos o sistemas financieros (idempotencia, conciliación).

## Soft skills
- Comunicación clara y trabajo en equipo.
- Autonomía y ownership.
